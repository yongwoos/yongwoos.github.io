---
title: 전력밀도
---
$$
\text{전력밀도} = \frac{\text{전력}}{\text{면적}}
$$

자유공간 전력밀도
$$
S = \frac{E^2}{120\pi}
$$

$E$: 전기장 세기 (V/m)

$120\pi$: 자유공간의 고유 임피던스 (약 377 Ω)

단위 면적을 통과하는 전력의 크기

즉, 전파가 공간으로 퍼져 나갈 때 1㎡의 면적에 얼마나 많은 전력이 도달하는가를 나타내는 물리량

## 1. 정의와 단위

\\[ S=\frac{P}{A} \\]

- \\(S\\): 전력밀도
- \\(P\\): 전력(W)
- \\(A\\): 면적(\\(m^2\\))

단위: \\[ W/m^2 \\]

예를 들어 100W의 전파 에너지가 10㎡의 면적을 통과한다면 전력밀도는 10W/㎡

## 2. 안테나에서 전력밀도

안테나에서 전파가 방사되면 공간으로 퍼져 나가면서 전력밀도가 감소

등방성 안테나(Isotropic Antenna)를 가정하면 전파는 구 형태로 퍼져 나가므로 거리 \\(r\\)에서의 전력밀도:

\\[ S=\frac{P_t}{4\pi r^2} \\]

- \\(P_t\\): 송신 전력
- \\(r\\): 안테나로부터의 거리
- \\(4\pi r^2\\): 반지름 \\(r\\)인 구의 표면적

즉, 전력밀도는 거리의 제곱에 반비례

## 3. 안테나 이득과 전력밀도

안테나 이득(Gain)이 있으면 특정 방향으로 전력을 더 집중해서 방사

따라서 특정 방향의 전력밀도:

\\[ S=\frac{P_tG}{4\pi r^2} \\]

\- \\(G\\): 해당 방향에 대한 안테나 이득(선형값)


| 개념     | 의미                  |
| ------ | ------------------- |
| 송신 전력  | 안테나에 공급하는 전력        |
| 전력밀도   | 단위 면적에 도달하는 전력      |
| 안테나 이득 | 특정 방향으로 전력을 집중하는 정도 |

핵심: 전력밀도는 전파가 공간상에 얼마나 강하게 분포하는지를 나타내는 값이야. 안테나 이득이 높으면 같은 송신 전력으로 특정 방향의 전력밀도를 높일 수 있어.

# 전력밀도 측정
대표적으로 전계강도(Electric Field Strength)를 측정해서 전력밀도로 환산하는 방법

## 1. 전계강도로 측정하는 방법

전파는 전기장(E)과 자기장(H)이 서로 직각으로 진동하면서 진행하는 전자기파

자유공간에서 전력밀도:

\\[ S=E \times H \\]

전자기파가 자유공간에서 진행할 때:

\\[ \frac{E}{H}=\eta_0\approx377\ \Omega \\]

따라서,

\\[ \boxed{S=\frac{E^2}{377}} \\]

- \\(E\\): 전계강도(V/m, RMS)
- \\(377\\): 자유공간의 고유 임피던스(Ω)
- \\(S\\): 평균 전력밀도(W/m²)

-> 전계강도를 측정하면 전력밀도를 구할 수 있음

## 3. 실제 계산 예시

전계강도 측정 결과가 10V/m라고 가정

\\[ S=\frac{10^2}{377} \\]

\\[ S\approx0.265\ W/m^2 \\]

따라서 전력밀도는 약 0.265W/m²

## 4. 정리

| 방법     | 측정 또는 계산 방식          |
| ------ | -------------------- |
| 직접 측정  | 전력밀도 측정용 프로브 사용      |
| 간접 측정  | 전계강도 측정 후 환산         |
| 이론적 계산 | 송신 전력, 안테나 이득, 거리 이용 |

핵심적으로 전력밀도는 단위 면적당 전력이므로 실제로 측정할 수 있고, 전파 분야에서는 전계강도를 측정해 전력밀도로 환산하는 방법도 많이 사용

단, \\(S=E^2/377\\)은 자유공간에서 진행하는 평면파 조건에 적용되는 식, 안테나 근접장처럼 복잡한 전자기장에서는 단순히 이 식을 적용할 수 없음
